## 📊 Project Overview

This project is an interactive Excel dashboard created to analyse the annual sales and order performance of Krishna Store for the year 2022.

The dashboard transforms sales and order data into meaningful charts, visualizations and business insights using Microsoft Excel.

## 🎯 Project Objective

The main objectives of this project are:

- Analyse monthly sales and order trends
- Compare sales performance between men and women
- Analyse different order statuses
- Identify the top 5 performing states
- Analyse orders by age group and gender
- Understand order channels and their contribution
- Provide interactive filtering for better analysis

## 📌 Dashboard Analysis

### 1. Orders vs Sales

This chart compares the number of orders with the total sales amount across different months of the year.

### 2. Sales: Men vs Women

This analysis compares sales contribution between male and female customers.

### 3. Order Status

This chart shows the distribution of orders based on their status:

- Delivered
- Refunded
- Returned
- Cancelled

### 4. Sales Top 5 States

This analysis identifies the top 5 states based on their sales performance.

### 5. Orders: Age vs Gender

This chart analyses orders across different age groups and genders, including:

- Adult
- Senior
- Teenage

### 6. Order Channel

This analysis shows the contribution of different order channels, including:

- Ajio
- Amazon
- Flipkart
- Meesho
- Myntra
- Nalli
- Others

## 🎛️ Interactive Filters

The dashboard contains interactive slicers for:

- Month
- Channel
- Category

These filters allow users to interact with the dashboard and analyse specific parts of the data.

## 💡 Key Business Insights

This dashboard helps identify:

- Monthly sales and order trends

- Order delivery and return patterns
- Top-performing states
- Important customer age groups
- Performance of different order channels
- Category-wise sales performance
